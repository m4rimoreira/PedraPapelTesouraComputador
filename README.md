# Pedra, Papel e Tesoura com Webcam

Versão **reconstruída** do projeto anterior com OpenCV e cvzone. Gestos: punho fechado = pedra, dois dedos = tesoura, mão aberta = papel. Contagem regressiva e placar.

```bash
python -m pip install -r requirements.txt
python main.py
```

Pressione **Espaço** para iniciar a rodada e **Esc** para sair. Teste em um ambiente Python compatível com as versões disponíveis de MediaPipe/cvzone.
